PLAN Unit 1 (code; test-first). CONTRACT R3 (typed-config; supersedes the R2 scheme-anchor string parse per Copilot review on PR #194 thread PRRT_kwDOSsAX4c6hzYmm). Keep _build_crawl_source_key (and its _CRAWL_OPTION_KEYS option construction) as the single builder grammar in src/docline/elt/source_keys.py, reused by both build_source_key and the new sanitizer. Add sanitize_source_key(config: SourceConfig) -> str that consumes the TYPED config (NOT the composed key string): for the two leak-scoped crawl configs (WebCrawlSource, ManifestUrlSource) sanitize the typed config.url via the existing public sanitize_source() (reuse, do not duplicate _CREDENTIAL_PARAM_PREFIXES) and RECOMPOSE the key through _build_crawl_source_key with the sanitized url, so the sanitized key is grammar-identical to the raw key except for the URL segment (immune to the manifest_url:<id>:<url> scheme-in-id ambiguity because no composed string is parsed; ManifestUrlSource.id is an unrestricted str per manifest_models.py:65). All other config types (LocalFileSource, GitHubRepoSource, ManifestLocalSource, ManifestGitSource) return build_source_key(config) BYTE-IDENTICAL (github_repo token handling DEFERRED). Add sanitize_source_key to __all__; update module docstring. make_job_id keeps hashing the raw build_source_key(config). Files: src/docline/elt/source_keys.py, tests/elt/test_source_keys.py (new). Size: S | Complexity: medium. ACCEPTANCE CRITERIA: (1) web_crawl config with userinfo + ?token=SECRET + options -> token+userinfo absent, prefix+option suffixes preserved; (2) a ManifestUrlSource whose id itself contains http:// and whose url carries ?token=SECRET -> token ABSENT and recomposed key preserves correct prefix/id/options (proves typed-config recompose is immune to scheme-in-id, the case the R2 string parse could not handle); (3) github_repo/local_file configs returned byte-identical AND an empty-option credentialed web_crawl config sanitized; (4) new unit tests pass; make_job_id input (raw build_source_key(config)) is not touched by the helper.
