Implement the SSRF-by-resolution guard on the SHARED fetch code to turn 064.010-T green. Code domain only (<=2 files: src/docline/fetch/url_policy.py, src/docline/fetch/http.py). Resolve each host and reject if ANY resolved address is loopback/private/link-local/metadata, and revalidate every redirect target at connect time. This hardens BOTH interfaces (CLI docline fetch and the MCP fetch tool) - a cross-interface behavior change (see plan Rollback/Risks). See docs/plans/2026-08-27-mcp-stdio-server-plan.md (Plan Hardening H6).

<!-- BEGIN:acceptance-criteria -->
- url_policy.py grows a resolve-and-classify path (or a new validate_resolved_host helper) that resolves a hostname to all A/AAAA records and rejects if ANY is loopback/private/link-local/metadata; literal-IP hosts keep the existing fast-path rejection. Normalize IPv4-mapped IPv6 (::ffff:a.b.c.d) to its IPv4 form before classification, and include ULA (fc00::/7), CGNAT (100.64.0.0/10), and 0.0.0.0 in the rejected set so alternate-encoding SSRF bypasses are covered.
- http.py enforces the resolved-host check at connect time on the initial URL AND on every redirect target (via the validating redirect handler / final-URL revalidation), not merely a netloc string compare.
- Address-pinned connect (closes DNS-rebinding): the connection is made to the specific VALIDATED IP (preserving the Host header / SNI for TLS) so urllib performs no second, unvalidated resolution. Validation and connection use the same address.
- Inherited proxies disabled for this fetcher: request.build_opener installs urllib's default ProxyHandler, which honors HTTP(S)_PROXY env vars and would hand the ORIGINAL hostname to a proxy that performs its own (second, unvalidated) DNS resolution - defeating the pin whenever proxy vars are set. This fetcher MUST install an explicitly EMPTY ProxyHandler({}) (NOT ProxyHandler(None), which falls back to getproxies() and would still honor macOS SystemConfiguration / Windows-registry system proxies) so NO proxy re-resolves the host on any platform; alternatively specify and implement an IP-pinned CONNECT path. A test with HTTP(S)_PROXY set proves the fetcher does not delegate resolution to a proxy (DNS-rebinding stays closed).
- 064.010-T harness passes green.
- The existing tests/fetch suite remains green; no unrelated behavior changed. Typed errors only (CrawlUrlRejectedError / DoclineError); no bare except.
- ruff check ., ruff format --check ., pyright src/ clean.
