Covering release unit (security remediation) for stash D6E758F5, a P2 credential leak surfaced by 059-S. _execute_single_source persists and ERROR-logs a raw web_crawl/manifest_url source_key whose embedded URL carries userinfo + credential query params, because sanitize_source() is a no-op on the crawl-prefixed key. Fix adds a scheme-anchored, prefix-restricted sanitize_source_key() helper routed through both the metadata.source persistence sink and the ERROR log (incl. traceback), while keeping make_job_id(source_key) on the raw key so job_id determinism is preserved. Source plan: docs/plans/2026-09-12-source-key-credential-sanitization-plan.md. NOT bundled with 059-S/060-S. github_repo token leak and credential-list expansion are deferred (P-021 watch).
