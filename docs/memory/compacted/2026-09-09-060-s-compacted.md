## Key learnings (durable)

1. A shipment closed via the single-artifact safe-close fallback (`archived_status: active`) is a
   **permanent** predecessor block for `pipeline-topology`-gated dependents — there is no
   supported after-the-fact correction short of operator-authorized gate override, because
   directly editing `archived_status` is provenance fabrication.
2. Prefer the P-015 cascade close whenever a shipment's manifest verifiably qualifies, specifically
   to avoid creating a new instance of the above problem for future dependents.
3. `backlogit shipment ship`'s documented deadlock is worktree-isolation-specific, not a general
   hazard of resident daemons — it succeeded from the primary workspace with daemons present.
4. When a review-fix commit corrects your own prose/docstring claim, verify the fix is byte-level
   accurate against the actual code paths (e.g. `CrawlUrlRejectedError`'s full `Raises:` set) —
   Copilot review caught three successive rounds of scope-adjacent inaccuracies in this session's
   own documentation before converging clean.
